# Titanic Survival Data Analysis

## Objective
Analyze the Titanic dataset using Python to discover patterns and insights through data cleaning, exploratory data analysis, and visualization.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
- Load Dataset
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Insights

## Dataset
Titanic Dataset (Kaggle)

## Results
Generated meaningful insights about passenger survival, gender, age, and passenger class.
